🚌 풀스택 버스 예매 시스템 (Bus Booking App)

2026.04 - 2026.05 | 개인 풀스택 프로젝트

React / Node.js / Oracle

Oracle DB, Node.js(Express), React를 기반으로 구축한 버스 예매 애플리케이션으로, 다중 사용자 환경에서의 좌석 동시성 제어와 실시간 중복 로그인 방지에 중점을 두고 설계했습니다.

Key Accomplishments

  • 원자적 트랜잭션 및 동시성 중복 예매 방지: 좌석 선점 검증 후 COMMIT/ROLLBACK 트랜잭션 처리와 Oracle DB의 UNIQUE 제약조건(UK_SCHEDULE_SEAT)을 결합해 동일 좌석 동시 승인 차단
  • 단일 세션 보장 및 실시간 중복 로그인 감지: 로그인 시 UUID 기반 CURRENT_TOKEN을 갱신하고, 프론트엔드 주기적 세션 검증(Polling)으로 기존 접속 브라우저 자동 강제 로그아웃 구현
  • 노선 시간표 조회 및 실시간 좌석 선택 UI: 한국 시간대(KST) 기준 노선·일정 동적 필터링, 예매 완료(PAID) 좌석 비활성화 및 선택 매수·결제 금액 실시간 계산 구현

DB 설계 및 구현 화면

USERS(세션 토큰 관리), SCHEDULES(노선 및 운행 회차), RESERVATIONS(회차·좌석 복합 유니크 제약) 3개 핵심 테이블 설계와 React·Express 풀스택 전 과정을 구현했습니다.

데이터베이스 스키마 설계 (USERS · SCHEDULES · RESERVATIONS)

단일 세션 토큰(CURRENT_TOKEN) 및 Polling 기반 중복 로그인 차단
